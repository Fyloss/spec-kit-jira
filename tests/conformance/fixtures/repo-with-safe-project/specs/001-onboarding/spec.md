# Feature Specification: Onboarding

We need new users to reach their first successful action quickly.

### User Story 1 - Guided first run (Priority: P1)

As a new user, I want a short guided tour on first login.

- **Given** a user signing in for the first time
- **When** the dashboard loads
- **Then** a three-step guided tour starts

### User Story 2 - Skip the tour (Priority: P2)

As a returning user, I want to skip the guided tour.

- **Given** a user who has completed onboarding before
- **When** the dashboard loads
- **Then** no tour is shown
