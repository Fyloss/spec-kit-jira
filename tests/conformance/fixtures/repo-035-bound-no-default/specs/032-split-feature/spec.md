# Feature Specification: Split feature

Two stories, two projects — the state an interrupted re-route leaves behind.

### User Story 1 - Export a report (Priority: P1)
<!-- speckit-jira story=1111111111111111 ticket=ALPHA-88 -->
As an analyst, I want to export a report.

- **Given** a signed-in analyst
- **When** they choose Export
- **Then** the report downloads

### User Story 2 - Share a report (Priority: P2)
<!-- speckit-jira story=2222222222222222 ticket=BETA-71 -->

- **Given** a signed-in analyst
- **When** they choose Share
- **Then** a link is produced
