# Feature Specification: Widget Management
<!-- speckit-jira spec=3333333333333333 ticket=TASKS-1 -->

We need to let users manage widgets end to end.

### User Story 1 - Create a widget (Priority: P1)
<!-- speckit-jira story=aaaaaaaaaaaaaaaa ticket=TASKS-2 -->

As a user, I want to create a widget.

- **Given** no widget exists
- **When** I create one
- **Then** it appears in my list

### User Story 2 - Rename a widget (Priority: P2)
<!-- speckit-jira story=1111111111111111 ticket=TASKS-3 -->

As a user, I want to rename a widget.

- **Given** a widget exists
- **When** I rename it
- **Then** the new name is shown

### User Story 3 - Delete a widget (Priority: P3)
<!-- speckit-jira story=2222222222222222 ticket=TASKS-4 -->

As a user, I want to delete a widget.

- **Given** a widget exists
- **When** I delete it
- **Then** it no longer appears in my list
