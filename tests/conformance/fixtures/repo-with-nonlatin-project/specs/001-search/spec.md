# Feature Specification: Search

We need users to find products by keyword across the catalogue.

### User Story 1 - Keyword search (Priority: P1)

As a shopper, I want to search products by keyword.

- **Given** a shopper on the catalogue page
- **When** they enter a keyword and submit
- **Then** matching products are shown

### User Story 2 - No results state (Priority: P2)

As a shopper, I want a clear message when nothing matches.

- **Given** a shopper searching for a keyword with no matches
- **When** they submit the search
- **Then** a "no results" message is shown
